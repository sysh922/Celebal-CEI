# SQL Sales Analysis using Superstore Dataset

## Overview

This project demonstrates the use of SQL for data analysis on the Superstore dataset. The objective was to explore customer sales behavior using Subqueries, Common Table Expressions (CTEs), Window Functions, and Joins.

## Project Structure

* **Week4_Assignment_SQL.ipynb**

  * Database creation and setup
  * Data import into SQLite
  * Creation of normalized tables:

    * Customers
    * Orders
    * Products
  * SQL queries using:

    * Subqueries
    * CTEs
    * Window Functions
    * Joins

* **Mini_Project_Customer_Sales_Insights.ipynb**

  * Top 5 customers by sales
  * Bottom 5 customers by sales
  * Customers with only one order
  * Customers with above-average sales
  * Highest order value per customer

## Technologies Used

* Python
* Pandas
* SQLite
* Jupyter Notebook

## Key SQL Concepts Covered

* Aggregate Functions
* Subqueries
* Correlated Subqueries
* Common Table Expressions (CTEs)
* Window Functions (`RANK()`, `ROW_NUMBER()`)
* JOIN Operations
* Data Analysis and Reporting

## Dataset

The analysis is based on the **Superstore Sales Dataset**, containing information about orders, customers, products, sales, profit, quantity, and discounts.
